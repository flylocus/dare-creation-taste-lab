# 创作味｜Dare to B2B

人类创作者与 AI 生成模型八维“创作味”图解和文章趣味鉴定器。纯 HTML、CSS、原生 JavaScript，单文件运行。

## 使用

下载 `index.html` 并直接用浏览器打开。无需安装依赖，无需后端。也可访问[在线版](https://dare-creation-taste-lab.trafly.chatgpt.site/)。

## 功能

- 八维标准特征图解、两组演示基准值与释义卡片
- 粘贴正文或读取 TXT、Markdown，以及部分含可选文字的 PDF
- 前端规则评分、三方雷达图、六列指标对比表
- 导出 1200×1260 SVG 或 2400×2520 PNG

## 结果边界

本项目是趣味游戏鉴定器。评分是词面规则估算，不能识别真实作者，也不具备学术检测或法律证明效力。三个预设样例的百分比是参考画像；点击“开始八维趣味鉴定”会根据当前正文重新评分。

PDF 解析采用浏览器原生能力，支持部分常见文本流；扫描件和复杂字体编码文件需要先提取文字或 OCR。
